# Rep My Block – Android App

This repository contains the Android (Kotlin) mobile application for **Rep My Block**.

Rep My Block is an offline-first civic technology platform designed to:
- Display candidates for election
- Provide transparent, verifiable election data
- Support grassroots organizing
- Restore trust in the electoral process

## Project Goals

- Offline-first architecture
- JSON-based data ingestion
- Transparent and auditable data model
- Alignment with RepMyBlock.org backend systems

## Tech Stack

- Android Studio
- Kotlin
- MVVM architecture
- Local JSON storage
- GitHub for collaboration
